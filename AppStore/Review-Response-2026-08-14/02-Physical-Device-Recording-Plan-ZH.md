## 录制标准

- 必须使用实体 iPhone；本次首选 `Jufei iP12`（iPhone 12，iOS 26.6）。iOS 26.6 是准备材料时 Apple 公布的最新 iOS。
- 使用与重新提交完全相同的 TestFlight/App Store build，不要用带 `Maren.storekit` 本地配置的开发演示代替最终 IAP 测试。
- 从 iPhone 主屏幕开始录制，第一步就是点击 Maren 图标启动 App。
- 建议 1080p 或设备原生分辨率、竖屏、无剪辑或仅做首尾裁剪。保证文字与系统购买页可读。
- 开启“勿扰模式”，隐藏私人通知；录制前清除通知中心，避免泄露个人信息。
- 不在画面里展示真实 Apple ID、邮箱、序列号、电话号码或其他个人信息。
- 推荐总时长 6–9 分钟。操作慢一点，每个关键页面停留 2–3 秒。
- 使用 TestFlight/Sandbox 交易完成一次购买；不要使用真实扣费账户。购买完成后必须展示已解锁页面。
- 如果系统购买确认页在录屏中被系统隐藏，另附一段从点击产品、确认 Sandbox 购买到 Premium 已激活的连续补充录屏，并在审核回复中说明。

## 录制前准备

### 1. 设备与 build

- [ ] iPhone 12 已升级到 iOS 26.6，解锁并保持亮屏。
- [ ] 已安装待提交 build，版本号与 build 号已记录。
- [ ] App Store Connect 三个 IAP 均为可提交/随版本审核状态，产品 ID 与代码一致。
- [ ] 月订阅与年订阅位于同一订阅组、同一等级。
- [ ] TestFlight/Sandbox 购买和恢复已经至少完整跑通一次。
- [ ] HealthKit、通知、Face ID 权限已通过重装 App 或系统设置重置到可再次显示首次授权提示的状态。

### 2. 演示数据

为了让趋势与 Premium 洞察有内容，建议录屏前准备一份专用演示数据。不要使用真实健康数据。

- 至少标记 3 个经期起始日，间隔约 27–32 天；每段可连续标记 3–4 天。
- 至少创建 5 条不同日期的每日记录，跨两个周期阶段，包含心情、能量和一个重复出现 2–3 次的症状。
- 至少创建 1 个自定义追踪项，例如 `Cravings` / `食欲变化`。
- 至少创建 1 个用药示例，例如 `Vitamin D`，不要使用真实处方或个人剂量信息。
- 准备 1 个免费态安装和 1 个可完成 Sandbox 购买的测试状态。录制正式片之前先练习一遍路径。

## 一镜到底脚本

### 00:00–00:20 启动与首次说明

1. 从主屏幕点击 Maren。
2. 如果是干净安装，依次展示 4 页 onboarding：隐私、本地存储、自适应预测、快速记录。
3. 点“开始使用”。
4. 旁白可省略；如果加字幕，只写事实，不写“医疗”“精准排卵”“安全期”等词。

### 00:20–01:20 日历与周期

1. 在“日历”页轻点某一天。
2. 依次展示流量选项，选择一个等级并保存。
3. 展示实际经期实心标记、预测虚线区间和四阶段颜色。
4. 点“了解各阶段”，缓慢滚动四个阶段说明。
5. 明确停留在免责声明：统计预测、仅供参考、不构成医学建议、不可作为避孕或备孕依据。
6. 返回日历，展示预测卡、范围、规律度或手动周期设置结果。

### 01:20–02:30 每日记录

1. 进入“今天”。
2. 选择心情、能量、疼痛、睡眠、体重和至少两个症状。
3. 添加一个不含个人信息的备注。
4. 点“＋ 自定义”，新建一个自定义追踪项并选中。
5. 点“保存今天的记录”，停留到出现“已保存”。
6. 如果已经准备了示例用药，展示“今日用药”打卡。

### 02:30–03:10 免费趋势与付费入口

1. 进入“趋势”。
2. 展示免费内容：历史周期、周期长度。
3. 展示锁定的洞察、30 天心情、体重趋势或追踪项频次。
4. 点“升级解锁”进入付费墙。

### 03:10–04:30 IAP 完整流程

1. 在付费墙顶部停留，展示 Premium 功能说明。
2. 依次展示年、月、终身三个产品的 StoreKit 本地化价格和周期。
3. 停留在自动续期、取消方式、Apple 处理支付、隐私政策、使用条款、恢复购买区域。
4. 点年订阅或月订阅，展示 Apple 系统购买确认页。
5. 用 TestFlight/Sandbox 完成购买。
6. 返回趋势页，展示付费墙自动关闭、Premium 洞察/图表解锁。
7. 进入设置，展示“Maren Premium 已激活”和“恢复购买”。
8. 如果要单独验证恢复：先用同一 Sandbox Apple ID 在另一台测试设备安装，再点“恢复购买”，不要为了录屏反复删除真实数据。

### 04:30–06:20 权限与设置

依次在“设置”页演示：

1. **通知**：点“开启通知权限”，展示系统通知授权框并允许。
2. 展示每日记录提醒、经期临近提醒；Premium 下展示提前天数、PMS 关怀、阶段智能提醒。
3. 进入“用药与补剂”，展示添加/编辑、每日提醒；Premium 下展示多时段与按周几排程。
4. **Apple Health**：点“连接 Apple 健康”，展示系统 HealthKit 授权页面，只包含经期/月经流量读写。
5. **Face ID / 密码锁**：开启后切到后台再回来，展示 LocalAuthentication 解锁流程。
6. 展示自定义追踪项管理和 PCOS 一般性科普页。
7. **数据存储**：最终 build（1.0.0 b2）**已移除 iCloud 同步**，设置页不应再出现「iCloud 同步」开关，录屏不得出现旧开关或旧文案。可顺带展示设置页隐私区「健康数据只存在这台设备上」并说明健康数据纯本机、不进入 iCloud/CloudKit。

### 06:20–07:20 导出与删除

1. 返回日历，点右上角分享按钮。
2. 展示系统分享页里的多份 CSV 和 PDF 文件名即可，不要将文件发给第三方。
3. 取消分享。
4. 进入“设置”底部，点“删除所有数据”。
5. 展示二次确认及将被删除的数据类型和数量。
6. **录屏时点击取消，不要真正删除演示数据**；回复 Apple 时说明此按钮会永久删除所有本地 Maren 数据。

### 07:20–08:00 无账号、无 UGC 社区与收尾

1. 停留在设置页，证明没有注册、登录或账户入口。
2. 如需字幕，写：`No Maren account is created. Private notes and custom labels are never published or shared with other users.`
3. 回到日历或趋势页结束录制。
